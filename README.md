# VidSort

Windows 免安装的本地视频播放器，播放时按 `Tab` 选分类即可把视频移动进对应文件夹（分类 = 磁盘目录）。

## 安装

1. 解压下载的 zip 到任意目录（建议非系统盘、路径不含特殊字符）。
2. 双击 `VidSort.exe` 运行。无需安装 .NET，运行时已内置。

## 首次使用

1. 首次启动会弹出**选择文件夹**对话框（窗口中央也有「选择文件夹…」按钮）。
2. 选中你的视频库根目录，例如 `D:\Videos`。
3. 程序自动把该路径写进同目录的 `config.json`，立刻扫描并播放第一个视频。

**不需要手动编辑任何配置文件。** 想换库：点右上角「更换目录」。

分类目录就是库根下的子文件夹，例如：

```
D:\Videos\            ← 库根（rootDir）
├─ 电视剧\
│   ├─ 国产\
└─ 电影\
```

在程序里新建分类会在磁盘上真的建同名文件夹；在资源管理器里手动新建的文件夹，回到程序按 `F5` 也会出现在分类菜单里。

## 界面

- **左侧边栏**：按目录浏览视频，下拉切换分类，**单击即播**；正在播放的那条前面带 `▶`。`B` 或左上角 `☰` 收起/展开。
- **底部控制条**：上一个 / 播放暂停 / 下一个、可拖动进度条、音量、快速归档、全屏。
- **右上角**：`分类`（打开分类浮层）、`更换目录`。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 播放/暂停 | `Space` 或点视频画面 |
| 后退/前进 5 秒 | `←` / `→` |
| 后退/前进 60 秒 | `Shift` + `←` / `→` |
| 调高/调低音量 | `↑` / `↓` |
| 下一个 | `N` 或 `PageDown` |
| 上一个 | `P` 或 `PageUp` |
| 打开/关闭分类浮层 | `Tab` |
| 浮层内选择分类 | `↑` / `↓` |
| 浮层内归档 | `Enter`（鼠标双击同一行等效） |
| 浮层内关闭 | `Esc` |
| 浮层内重命名分类 | `F2` |
| 从菜单隐藏分类 | `Delete` |
| 显示隐藏项 | `Shift` + `H` |
| 新建分类 | 浮层最后一行「＋ 新建分类…」按 `Enter` |
| 撤销上一次归档 | `Ctrl` + `Z`（归档成功后点 Toast 上的「撤销」等效） |
| 侧边栏开关 | `B` 或左上角 `☰` |
| 刷新（重扫磁盘） | `F5` |
| 全屏切换 | `F` 或底部「全屏」按钮（进入后按钮变成「退出全屏」） |
| 静音 | `M` |

## 归档的语义

选中分类并确认后，当前视频文件会被**移动**到 `库根/分类路径/` 下（不是复制，源位置不留副本）。播放自动跳到下一条（队列空时提示「已全部归档」）。

- 目标已有同名文件：默认自动改名为 `xxx (2).mp4`（可在 `config.json` 的 `onConflict` 改为 `Skip` / `Overwrite`）。
- 归档后可 `Ctrl+Z` 撤销，文件移回原处。
- 底部「快速归档」按钮会记住上次用的分类，文字显示为 `归档到「电视剧/国产」`，再点一次即可归档到同一处。

## 已知限制

- 只支持 64 位 Windows。
- exe 未签名，首次运行 SmartScreen/Defender 可能提示。
- MKV/HEVC 走 libVLC 解码；遇到不支持的编码会提示播放失败。
- **解压后首次归档可能界面卡死**（libVLC 在冷启动时释放视频输出会阻塞），重启后不再复现。这是已知问题，见仓库 issue。

## 目录结构

以下文件位于 `VidSort.exe` 同目录：

- `config.json`：`rootDir` 库根目录、`hiddenCategories` 隐藏分类、`showHidden` 是否显示隐藏项、`onConflict` 同名冲突策略、`lastCategory` 上次归档分类。首次启动自动生成，程序内改动会自动保存。
- `journal.json`：归档撤销日志，可以删除；删除后无法撤销此前的归档。
