# VidSort

Windows 免安装的本地视频播放器，播放时按 `Tab` 选分类即可把视频移动进对应文件夹（分类=文件夹）。

## 安装

1. 解压下载的 zip。
2. 双击 `VidSort.exe` 运行。无需安装 .NET，运行时已内置。

## 首次使用

1. 首次启动后，程序会在同目录自动生成 `config.json`。
2. 打开 `config.json`，把 `rootDir` 改成本地视频库根目录，例如：

```json
{
  "rootDir": "D:\\Videos"
}
```

3. 重启 VidSort，程序会扫描并自动播放第一个视频。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 播放/暂停 | `Space` |
| 后退/前进 5 秒 | `←` / `→` |
| 后退/前进 60 秒 | `Shift` + `←` / `→` |
| 调高/调低音量 | `↑` / `↓` |
| 下一个 | `N` 或 `PageDown` |
| 上一个 | `P` 或 `PageUp` |
| 打开分类浮层 | `Tab` |
| 浮层内选择分类 | `↑` / `↓` |
| 浮层内归档 | `Enter` |
| 浮层内关闭 | `Esc` |
| 浮层内重命名分类 | `F2` |
| 从菜单隐藏分类 | `Delete` |
| 显示隐藏项 | `Shift` + `H` |
| 新建分类 | 在分类浮层最后一行按 `Enter` |
| 撤销上一次归档 | `Ctrl` + `Z` |
| 刷新 | `F5` |
| 全屏 | `F` |
| 静音 | `M` |

## 重要说明

**归档是真实的文件移动，源位置不留副本；撤销是把文件移回原处；分类即磁盘目录，可以在资源管理器里直接增删，程序里按 `F5` 刷新即可。**

## 已知限制

- 只支持 64 位 Windows。
- exe 未签名，首次运行 SmartScreen/Defender 可能提示。
- MKV/HEVC 走 libVLC 解码，遇到不支持的编码会提示播放失败。

## 目录结构

以下文件位于 `VidSort.exe` 同目录：

- `config.json`：库根目录、隐藏分类、冲突策略；首次启动时自动生成。
- `journal.json`：撤销日志，可以删除；删除后无法继续撤销此前的归档。

## 手工验收清单

1. 改好 `rootDir` 后，能自动播放第一个视频。
2. 按 `N` 能切换到下一个视频。
3. 按 `Tab` 选择一个分类并按 `Enter`，文件真的出现在该文件夹，播放自动跳到下一条。
4. 按 `Ctrl+Z`，文件回到原位。
5. 在资源管理器里新建一个文件夹，按 `F5` 后菜单里出现该分类。
